📌 Project Overview

IoT-Based Home Automation Using Digital Logic is a smart home simulation project designed to demonstrate the use of sensors, digital logic, actuators, remote control, and power optimization in a home automation system.The project is implemented as a Python software simulation with a Graphical User Interface (GUI). It allows users to simulate different sensor conditions and observe how the home appliances respond automatically.

🎯 Objectives

To develop a simple home automation system using digital logic.
To simulate LDR, temperature, and motion sensors.
To implement 74HC08 AND-gate logic using Python.
To control simulated appliances such as LED, motor/fan, and servo door.
To provide manual and remote-control functionality.
To demonstrate power optimization by switching unnecessary appliances OFF.
To provide an easy-to-use GUI for monitoring and controlling the system.

📊 Results

The project successfully simulated an IoT-based home automation system using Python and digital logic. LDR, temperature, and PIR sensors were simulated through a GUI, and the 74HC08 AND-gate logic was used for automatic LED control. The system also simulated a motor/fan, servo door, remote control, and power optimization.
The GUI displayed the sensor values, actuator status, digital logic output, and power-saving information in real time.
